# Surface: vaskel.com landing page

The page helps prospective hosts understand vaskel. and install their own
instance. Friends can explore the product through the interactive preview.
There is no account sign-up on the site. The primary action is Deploy your own,
with GitHub for the source and Copy prompt for the complete agent setup request.

[DESIGN.md](../../DESIGN.md) owns the page's design system and layout.
[INSTALL.md](../../../../INSTALL.md) owns installation; the build serves that
file at `/INSTALL.md`. Reference costs come from
[cost-scenarios.json](../../../../docs/cost-scenarios.json), with planning ranges
and dated assumptions in [Costs](../../../../docs/costs.md).

## Direction contract

THESIS: The install file is the page. Step 0 is the product itself, followed by
prerequisites, agent-led setup, becoming the host, inviting people and costs.
The wordmark band carries the sentence and the deployment action. The product
preview supplies the evidence, without feature cards or fabricated social proof.

OWN-WORLD: Use the shared Lounge tokens: warm neutrals, terracotta accent,
ID-derived person hues and the dark call stage. Typography uses IBM Plex Sans
and Mono with regional Plyra Sans faces for CJK. Hairlines and shared shadows
provide structure. The site adds only the terminal colour; numerical styles
belong in the design guide and source, not a second inventory here.

STORY: The preview opens on the Lounge voice stage. Visitors can open general,
memes or a DM and see the call follow them through the dock or picture-in-picture
view. The browser selects one of the four supported languages; there is no
display-language switcher. A host copies the full setup request for their agent,
while the remaining steps explain the installation and its costs.

FORM: The wordmark band sits above a heading row containing What you get and the
install-file link with Copy prompt. One operable workspace fills the exhibit,
without additional scene panes or synthetic-preview captions. The setup exhibit
is an abridged agent session following INSTALL.md. The footer contains the
wordmark and links. The general-room arrival sequence respects reduced motion,
and its still frame is complete. No promotional badges, testimonial cards,
fabricated benchmarks or decorative imagery are added.
